# DraftLock

DraftLock is a data-encrypted, auto-synchronizing module for real-time collaboration and disaster recovery within a secure system.

DraftLock is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftLock.git`
2. `cd DraftLock`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DraftLock, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
